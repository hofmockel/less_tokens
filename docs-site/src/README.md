# docs-site source notes

The first HTML documentation implementation is generated by
`docs-site/scripts/build_docs.py`.

Authored narrative, page inventory, and slide text live in that script so the
initial site can stay dependency-light and reproducible. Generated data is
derived from code registries and checked-in aggregate notes, then written to
`docs-site/site/generated/`.

As the HTML layer grows, larger authored sections can move into this directory
as plain HTML or Markdown-like partials while preserving the same commands:

```bash
python3 docs-site/scripts/build_docs.py
python3 docs-site/scripts/check_docs.py
```
