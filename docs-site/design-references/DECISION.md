# Homepage visual direction

Decision recorded: 2026-07-14

Selected direction: **03 — Systems Map**

The systems-map direction is the homepage foundation because it explains the
product visually, gives examples room to breathe, and can scale from a concise
hero into deeper strategy diagrams. Its palette, hard-edged controls, token
routing model, and explanatory layout should guide future site work.
